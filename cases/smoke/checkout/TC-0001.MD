# TC-0001: Add a catalog product to the basket and start checkout

## Purpose

Verify that a buyer can find a product in the catalog, add it to the basket, see the correct basket line item, and open the checkout page.

Business logic under test: adding one catalog item creates one basket line with the selected product name, SKU, quantity, and price; the checkout action is available from the basket.

Not covered:

- payment authorization
- order fulfillment
- email notifications
- inventory changes after order placement

## Environment

| Field | Value |
|---|---|
| Environment | demo |
| Application | Storefront |
| Base URL | `${ESHOP_BASE_URL}` |
| Start page | `/catalog` |
| User | `ESHOP_BUYER` |
| Role | buyer |

Credentials are resolved from environment variables:

- `ESHOP_BUYER_LOGIN`
- `ESHOP_BUYER_PASSWORD`

## Test Data

The product exists in the demo catalog and can be added to the basket:

| Field | Value |
|---|---|
| Product SKU | `SKU-DEMO-MUG` |
| Product Name | `Demo Coffee Mug` |
| Product Category | `Accessories` |
| Product Price | `$12.00` |
| Quantity | `1` |
| Product URL | `/catalog/products/sku-demo-mug` |
| Cart URL | `/basket` |
| Checkout URL | `/checkout` |

## Constraints

- Do not place a real order.
- Do not use production accounts, payment cards, or live payment providers.
- Keep the basket isolated to the test buyer account.
- If the basket already contains items, clear it before adding the sample product.

## Cleanup

Remove the sample product from the basket or reset the basket after the test.

## Steps

1. Open the sign-in page: `${ESHOP_BASE_URL}/account/sign-in`.
2. Sign in as `ESHOP_BUYER`.
3. Open the catalog page: `${ESHOP_BASE_URL}/catalog`.
4. Search for product `Demo Coffee Mug`.
5. Open the product details page for SKU `SKU-DEMO-MUG`.
6. Click the "Add to basket" button for the product.
7. Open the basket page: `${ESHOP_BASE_URL}/basket`.
8. Verify that the basket contains one line item with:
   - product name `Demo Coffee Mug`
   - SKU `SKU-DEMO-MUG`
   - quantity `1`
   - price `$12.00`
9. Click the "Checkout" button.
10. Verify that the checkout page is opened.

## Expected Results

1. The buyer signs in successfully.
2. The catalog search returns the product `Demo Coffee Mug`.
3. The product details page contains SKU `SKU-DEMO-MUG` and an active "Add to basket" button.
4. The basket contains one line item for `Demo Coffee Mug`.
5. The basket line item shows SKU `SKU-DEMO-MUG`, quantity `1`, and price `$12.00`.
6. Clicking "Checkout" opens `${ESHOP_BASE_URL}/checkout`.
7. No order is submitted during the test.
